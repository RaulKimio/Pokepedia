# Poképédia

Site educativo sobre os Pokémon da primeira geração, desenvolvido em HTML5 e CSS para a disciplina de Introdução à Web. O projeto apresenta os 151 Pokémon da região de Kanto e informações sobre seus tipos, evoluções e ginásios.

## Páginas

- **Início** (`Trabalho/HTML/index.html`): apresentação do projeto, Pokémon em destaque, curiosidades e vídeo.
- **Pokédex** (`Trabalho/HTML/pokedex.html`): cards dos 151 Pokémon, com informações e filtros por tipo.
- **Tipos** (`Trabalho/HTML/tipos.html`): consulta aos tipos Pokémon e suas relações.
- **Ginásio** (`Trabalho/HTML/ginasio.html`): líderes e equipes dos oito ginásios de Kanto.
- **Contribuir** (`Trabalho/HTML/contribuir.html`): formulário para enviar sugestões ao projeto.

## Tecnologias

- HTML5 semântico e CSS3.
- [Bulma](https://bulma.io/), carregado pelas folhas de estilo, para componentes e layout.
- JavaScript somente para abrir e fechar o menu hambúrguer da navegação em telas menores.

## Estrutura

```text
Trabalho/
├── CSS/       folhas de estilo das páginas
├── HTML/      páginas do site
├── imagens/   imagens, ícones e outros recursos visuais
└── JS/        script da navegação
```

## Como abrir

Abra `Trabalho/HTML/index.html` no navegador. Para testar o menu e a navegação entre páginas, mantenha a estrutura de pastas do projeto. O Bulma é carregado pela internet, então alguns estilos dependem de conexão.
